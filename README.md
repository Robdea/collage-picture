# Collage Picture 

Collage Picture es un proyecto desarrollado en React con TypeScript. Se trata de una réplica minimalista de algunas funcionalidades del sitio Pinterest, enfocada en la práctica de diseño de interfaces (UI) y replicación de estilos y comportamientos de sitios existentes.

Este proyecto también sirve como ejercicio de TypeScript con React, utilizando la sintaxis tsx.

### 🚀 Tecnologías utilizadas
- ⚛️ React + Vite + TypeScript

- 🌐 React Router DOM
